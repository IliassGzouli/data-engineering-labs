# Data Engineering Labs

A collection of small and medium-sized projects developed to practice data engineering concepts, tools, and best practices.

## Projects

### Real Estate Airflow PostgreSQL Pipeline

An end-to-end ETL pipeline for processing real estate data.

Main features:

- Data extraction from CSV files
- Data cleaning and transformation with Pandas
- Data quality validation
- Loading into PostgreSQL
- Workflow orchestration with Apache Airflow
- Containerization with Docker
- Unit testing with Pytest

## Technologies

- Python
- Pandas
- PostgreSQL
- SQLAlchemy
- Docker
- Apache Airflow
- Pytest
- Git and GitHub
